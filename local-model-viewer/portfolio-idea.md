# Modeling Portfolio Concept

This site is meant to be a simple, focused portfolio viewer for 3D models.

## Core idea
- Show selected models in a clean, minimal page.
- Keep the camera fixed so the framing stays consistent.
- Let the model rotate left and right when the user drags horizontally.
- Avoid pan and zoom so the view stays controlled.
- Use a studio-style lighting setup so the model reads clearly.

## Interaction style
- Drag left or right to rotate the model around the vertical axis.
- No free orbiting.
- No zooming.
- No panning.

## Visual direction
- Neutral background.
- Soft studio lighting.
- Clean layout with very little extra UI.
- The model should be the main focus.

## File strategy
- For a portfolio site, the models should be hosted with the site.
- Use `.glb` files for the smoothest support.
- If textures are needed, embed them inside the `.glb` when possible.

## Intended feel
- More like a presentation space than a testing tool.
- Simple, controlled, and polished.
- Built for viewing finished work quickly without distractions.
